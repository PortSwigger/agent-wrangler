# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately rather than opening a public issue.

Preferred: use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
via the **Security** tab of this repository ("Report a vulnerability").

We'll acknowledge reports as soon as possible and keep you updated as we investigate and address the issue.

## Scope

This policy covers the Agent Wrangler codebase in this repository. It does not cover PortSwigger's
products (e.g. Burp Suite) — see [portswigger.net](https://portswigger.net) for how to report issues there.
