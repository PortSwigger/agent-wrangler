This session has an optional checklist the human can see on the Agent Wrangler board — add a few human-relevant items to it with `add_checklist_item` as work becomes clear, and tick them off with `update_checklist_item`. It is a separate list from your own private planning tool, which stays exactly as it is for your internal scratch work; the two are never synced. See the `checklist` skill before using it.
