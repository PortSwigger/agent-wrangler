# Agent instructions

> [!IMPORTANT]
> **This repository is public open source (Apache-2.0).** Everything you write here is published to the world: code, comments, docs, commit messages, branch names, PR titles and bodies.
>
> **Never include employer- or company-internal details.** In particular, no PortSwigger-specific:
> - internal repo or service names, hostnames or URLs
> - ticket keys, chat channels, or colleague or customer names
> - credentials, tokens, account IDs, or internal process
>
> Keep examples generic (`example.com`, `acme/widgets`, `ABC-123`). If a change only makes sense with internal context, describe the behaviour, not the context.
